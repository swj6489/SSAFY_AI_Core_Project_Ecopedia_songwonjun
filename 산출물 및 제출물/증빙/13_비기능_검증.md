# 비기능 요구사항 검증

점검일: 2026-10-23. 대상: 바탕화면 ecopedia의 현재 구현. 앱 작성자: 송원준. 점검자 이름은 기재하지 않음.

## NF2001 응답 시간

GMS gpt-5.4-mini와 실제 EcoService를 사용하여 같은 프로세스에서 같은 질문을 연속 실행했다. 질문은 “삵은 주로 무엇을 먹으며 어떤 시간대에 활동하는가?”이다. 자동 수집은 활성화했고 기존 캐시·색인을 유지했다. 측정은 서비스 응답 전체의 경과 시간이며 설치·초기화 시간은 포함하지 않는다.

| 구분 | 경과 시간 | 인용 근거 수 | 검색어 캐시 적중 |
| --- | ---: | ---: | ---: |
| 첫 실행 | 6.521초 | 1 | 1/3 |
| 동일 질문 반복 | 27.842초 | 1 | 2/3 |

이번 점검에서 실행 전에 정한 임시 목표는 각 응답 30초 이내이며 두 실행이 이를 충족했다. 이는 명세서의 공식 SLA가 아니며 전체 질문의 성능 보장도 아니다. 반복 실행이 오히려 더 느렸으므로 캐시가 항상 응답을 단축한다고 결론 내리지 않는다. 검색어 생성 등 모델 호출 및 외부 서비스 지연에 따라 달라질 수 있으나 이번 측정만으로 원인을 확정하지 않았다. 신규 컴퓨터·빈 캐시의 최초 수집 및 다수 표본의 평균·상위 지연은 미검증이다.

판정: 이 점검 범위와 임시 목표에서 통과. 원시 기록: `13_응답시간_실측.json`.

## NF2003·NF2004 키 관리와 내부 정보 비노출

현재 배포 대상 소스·산출물 및 기존 기록 ZIP에서 압축·Office 파일 내부까지 197개 항목을 검사했다. 로컬 환경에서 알고 있는 실제 키 값이 발견되지 않았고 압축 내부에 `.env`도 없었다. 실제 키 값 자체는 결과 파일에 기록하지 않았다. 로컬 전용 `.env`, 가상환경, 런타임 등의 제외 범위는 `12_비밀정보_파일점검.json`에 명시했다.

실제 `app.py`와 `EcoService.answer`를 실행하는 Streamlit AppTest에 인위적 예외를 주입했다. 이 테스트는 의존성을 격리했으며 실제 키나 외부 API를 사용하지 않았다.

- 화면에는 “처리하지 못했습니다. 연결·모델 설정을 확인한 뒤 다시 시도해 주세요.”라는 일반 안내만 표시됐다.
- 가짜 키, 내부 프롬프트 표식, traceback이 렌더링된 UI에 없었다. 앱 예외 요소 수는 0이었다.
- 격리된 로그에서 가짜 키는 `[REDACTED]`로 마스킹됐다.

판정: 현재 알려진 키의 파일 검사와 인위적 오류 UI·로그 테스트 범위에서 통과. 원시 기록: `12_비밀정보_파일점검.json`, `14_오류정보_비노출_UI검증.json`.

한계: 파일 검사는 이미지 픽셀의 OCR이 아니며 알지 못하는 비밀값이나 앞으로 생성될 ZIP을 보장하지 않는다. AppTest는 실제 앱의 UI 요소 검사이지만 브라우저 스크린샷은 아니다. 이 결과는 전체 보안 감사나 프롬프트 공격 전반에 대한 검증을 뜻하지 않는다.

## 반영 범위

체크리스트의 비기능 미확인 두 행(NF2001, NF2003·NF2004)에만 판정·근거·한계를 반영한다. 앱 기능 변경이나 성능 최적화는 수행하지 않았다. 기존 기록용 ZIP은 갱신하지 않았으며 새 증빙은 산출물 및 제출물 폴더에 별도 보관한다.
