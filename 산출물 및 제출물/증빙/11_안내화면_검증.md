# 체크리스트 13번 안내 화면 검증

검증일: 2026-10-23

## 확인 결과

실제 app.py를 Streamlit AppTest로 실행하여 아래 세 조건을 확인했다. 운영 .env와 실제 벡터 색인을 변경하지 않았으며 외부 수집·AI 호출도 하지 않았다. 설정·종 데이터·사진·외부 서비스 의존성을 격리된 테스트 대역으로 주입했다.

| 조건 | 실제 실행에서 확인한 결과 | 자동 테스트 |
|---|---|---|
| 키 누락 | ‘종 목록은 바로 탐색할 수 있습니다. AI 질문·조건 탐색은 .env에 API 키를 설정한 뒤 사용할 수 있습니다.’ 안내와 채팅 입력 비활성화 | 통과 |
| 색인 없음 | 실제 EcoService.answer의 메타데이터 사전 검사에서 ‘종 메타데이터 색인이 없습니다. 먼저 색인 버튼을 눌러 주세요.’ 경고가 화면 요소에 표시됨 | 통과 |
| 진행 상태 | 질문 제출 시 ‘질문을 처리하고 있습니다.’ 상태 영역이 펼쳐지고, 테스트 수집·생성 종료 후 테스트 답변이 표시됨 | 통과 |

결과 원문과 원본 app.py 해시는 `11_안내화면_자동검증.json`에 기록했다. 진행 상태 검증의 수집·생성은 테스트 대역이므로 실제 GMS 응답 품질이나 처리 속도 검증으로 사용하지 않는다.

## 남은 증빙

브라우저 캡처를 위해 별도 Streamlit 검증 서버를 열었으나 Browser Use가 localhost 및 127.0.0.1의 테스트 포트에 연결하지 못했다. 실제 브라우저에서 키 누락·빈 색인 화면을 캡처한 것으로 표시하지 않는다. 기존 `06_처리상태.png`는 이전 실제 질문의 진행 상태 증빙이며 새로운 두 오류 화면의 증빙을 대신하지 않는다.

따라서 자동 UI 동작은 확인했지만 제출용 화면 캡처가 아직 부족하므로 체크리스트 13번은 미확인으로 유지했다. 화면 캡처를 추가한 뒤 최종 판정한다. 실제 키를 제거하거나 운영 색인을 삭제하는 방법 대신 격리 테스트를 사용해야 한다.
