## 1 프로젝트 개요

EcoPedia는 국내 멸종위기 야생생물의 기본 정보와 외부 설명 문서를 검색하여 질문에 답하고, 답변에 사용한 근거를 함께 보여주는 서비스이다. 사용자는 국명·학명·분류군·숫자 등급으로 종을 선택하고, 종별 질문, 자연어 조건 탐색, 두 종 생태 비교를 이용한다.

개인 취향에 따라 순위가 달라지는 추천보다 출처로 확인 가능한 정보를 제공하는 데 목적을 둔다. 답변의 근거가 없으면 확인되지 않는다고 안내하며, 생태정보의 과거 기록을 현재 사실로 단정하지 않는다.

본 문서는 기능의 요구사항과 수용 기준을 정의하고, 작성일 현재의 구현 범위를 구분한다. 기능 구현과 제출용 검증 완료는 별개이다. 실제 실행 화면, 요구사항 대조표, 테스트 결과표, 셀프·상호 체크리스트는 별도 검증 산출물로 제출한다.

### 1.1 서비스 범위

- 종 목록과 기본 속성의 로드 및 벡터 색인
- 질문에서 검색어 추출, 외부 문서 후보 선별 및 수집
- 종별 근거 검색과 LangGraph 기반 답변 생성
- 답변의 근거 번호, 문서 제목, 출처 및 이용 조건 표시
- 자연어 조건으로 종 찾기와 종별 대화 연결
- 서로 다른 두 종의 생태정보 비교
- 대표 사진, 정보 확보 상태, 추천 질문, 라이트·다크 화면 제공

로그인, 서버 DB 기반 회원별 대화 보관, 282종 전수 생태자료 확보, 실시간 개체수 조사, 현행 법정 목록 전수 대조는 현재 범위에 포함하지 않는다. 대화는 현재 Streamlit 세션에서 종별로 관리한다.

### 1.2 상태 구분

| 상태 | 의미 |
|---|---|
| 구현 | 해당 기능의 코드와 실행 경로가 구현되어 있다. 모든 종의 정확성이나 제출 검증 완료를 의미하지 않는다. |
| 부분 구현 | 관련 코드 또는 일부 확인 결과는 있지만 요구된 비교·실증·문서가 더 필요하다. |
| 확인 필요 | 정량 평가, 권리 확인 또는 사용자 점검 등 추가 확인이 필요하다. |
| 미선택 | 현재 심화 구현 범위에 포함하지 않는다. |

## 2 도메인 선정과 데이터 근거

### 2.1 항목 수와 출처

| 항목 | 확보 내용 및 범위 |
|---|---|
| 종 메타데이터 | 국립생태원 제공 목록 기반 282종으로 약 100건 이상 조건 충족 |
| 법정 등급 분포 | 1급 68종, 2급 214종. 내부 값은 정수 1 또는 2 |
| 기준일 | 2022-12-09 개정 목록 기준. 현재 법령과 전수 대조한 목록이 아님 |
| 기본 속성 | 고정 종 ID, 국명, 학명, 분류군, 등급, 원문 출처, 자료 기준일 |
| 외부 설명 | 한국어 위키백과 우선. 생태자료 보강 시 학명으로 확인한 영문 위키백과 추가 활용 |
| 보강 현황 | 대표 20종에서 항목별 원문 인용 90건. 60개 생태 항목 중 원문 대조 48개, 관련 표현 5개, 미확보 7개 |
| 보강 한계 | 12종은 세 항목 모두 원문 대조 정보 확보. 전체 282종의 생태정보 확보 완료가 아님 |

원본 목록에 없는 서식 환경·국내 분포·주요 위협 요인 값은 빈 문자열로 보존한다. 외부 문서의 인용과 출처는 별도 캐시·파생 색인으로 저장하며, 원본 목록을 근거 없이 채우지 않는다. 외부 문서의 확보 가능성은 확인했으나 모든 종에서 같은 수준의 설명 문서를 확보한 것은 아니다.

### 2.2 자료별 이용 조건

| 자료 | 사용 방식 | 이용 조건과 확인 사항 |
|---|---|---|
| 국립생태원 종 목록 | 기본 사실 항목 및 기준일 저장 | 원문 출처를 기록한다. 목록 파일의 개별 이용허락 검토는 남아 있어 배포 권리 확인 완료로 표시하지 않는다. |
| 한국어·영문 위키백과 텍스트 | 종 문서 및 관련 문서 수집, 발췌·분류 | 기본 CC BY-SA 4.0 조건에 따라 원문 URL·리비전·라이선스를 보존한다. 변경 고지와 공유 시 동일조건 적용 범위를 준수하고 문서별 예외를 확인한다. |
| 위키미디어 사진 | 파일별 허용 조건이 확인된 원격 이미지 표시 | 텍스트 라이선스를 사진에 일괄 적용하지 않는다. 저작자·파일 원문·라이선스를 표시한다. 대체 사진은 Public domain·CC0로 확인되는 경우만 사용한다. |
| Wikidata | 학명 및 대표 이미지 연결 확인 | 텍스트·이미지 자체의 이용허락을 대신하지 않는다. 연결된 사진은 별도로 권리 조건을 확인한다. |
| 로컬 PDF·TXT | 승인된 manifest를 통한 추가 수집 경로 | 출처·파일명·PDF 페이지·이용 조건을 기입하고 이용허락 확인 항목을 통과한 자료만 허용한다. |

국립생태원 공식 도감과 국립생물자원관 본문은 이용 조건 미확정 또는 변경금지 관련 검토가 필요해 자동 수집하지 않는다. 출처 기록과 권리 확인 완료는 서로 다른 상태로 관리한다.

### 2.3 근거가 필요한 대표 질문

| 질문 예시 | 근거가 필요한 이유 |
|---|---|
| 산양은 어떤 서식 환경에 살고 국내 어디에 분포하는가 | 해외 분포, 과거 기록, 국내 기록을 혼동할 수 있다. |
| 사향노루의 주요 위협 요인은 무엇인가 | 해당 종의 문서 없이 다른 종의 일반적인 위협을 적용할 수 있다. |
| 산양과 사향노루의 서식 환경과 위협 요인은 어떻게 다른가 | 두 종의 각각의 출처를 검색하고 주장별로 구분해야 한다. |
| 산림에 서식하는 1급 포유류를 찾아달라 | 등급·분류군 외에도 실제 서식지 근거가 필요하다. |
| 특정 날짜의 정확한 야생 삵 개체수는 몇 마리인가 | 자료에 없는 수치를 생성하지 않고 확인되지 않는다고 답해야 한다. |

### 2.4 안내 원칙

일반 생물정보 학습용 서비스로, 건강·금융과 같은 전문가 조언 대체 도메인은 아니다. 다만 법정 등급의 현행성, 멸종위기종의 포획·사육·거래 가능 여부, 정확한 개체수 또는 서식 여부를 확정하는 용도로 사용하지 않는다. 위치 정보로 포획이나 서식지 교란을 유도하는 기능은 제공하지 않는다.

## 3 항목 텍스트와 검색 범위

종 1건은 아래 속성을 하나의 검색 텍스트로 구성한다. 종 ID와 출처 URL 등은 검색 필터·근거 표시에 사용할 메타데이터로 함께 저장한다.

```text
국명: 삵
학명: Prionailurus bengalensis
분류군: 포유류
멸종위기 등급: 2급
국내 분포: 확인된 정보 없음
서식 환경: 확인된 정보 없음
주요 위협 요인: 확인된 정보 없음
자료 기준일: 2022-12-09
```

위 예시의 미확인 표시는 원본 메타데이터 필드가 비어 있다는 뜻이다. 외부 문서에 저장된 별도 근거까지 없다는 의미가 아니다. 종별 답변과 조건 탐색은 확보된 외부 생태 근거를 함께 사용할 수 있어야 한다.

| 저장 영역 | 요구 역할 |
|---|---|
| species_meta | 종당 1개 기본 텍스트. 선택 종 메타데이터를 근거에 강제 포함 |
| species_docs | 외부 문서 청크와 출처를 가진 생태정보 발췌. 종 ID로 검색 범위 제한 |
| SQLite 수집 캐시 | 성공한 검색어, 문서 본문, 문서 확인 결과 및 추출 결과의 영속 재사용 |

기본 설정은 청크 1,000자, 중복 200자, 외부 문서 Top-k 4개, 유사도 검색이다. 한 종의 최대 근거는 메타데이터 1개와 외부 청크 4개이며 중복 제거 후 줄어들 수 있다. 자연어 탐색의 기본 후보 수는 20개로, 전체 종의 전수 결과를 보장하지 않는다. 설정 선택 이유와 변경 실험 결과는 RAG 파이프라인 설계문서에서 별도로 설명한다.

## 4 필수 기능 요구사항

필수 요구사항 F2001부터 F2012까지의 범위는 유지하고, 항목을 멸종위기종 도메인에 맞춰 구체화한다.

| 번호 | 분류 및 요구사항명 | 상세 요구사항과 수용 기준 | 우선순위 | 현황 |
|---|---|---|---|---|
| F2001 | 데이터 · 종 메타데이터 적재 | 282종 JSON을 로드하고 종마다 하나의 색인 텍스트를 구성한다. 고정 ID와 국명·학명·분류군·등급·기준일을 보존한다. 누락 생태 속성은 미확인으로 표시한다. 로드 건수와 대표 텍스트 출력으로 확인한다. | 필수 | 구현 |
| F2002 | 색인 · 종 메타데이터 색인 | 항목 텍스트를 임베딩하여 species_meta에 색인한다. meta:종ID를 식별자로 사용하고 재실행해도 중복 건수가 늘지 않아야 한다. 화면에서 색인 건수를 확인할 수 있어야 한다. | 필수 | 구현 |
| F2003 | 프롬프트 · 검색어 추출 | 도메인 전문가 역할의 프롬프트로 선택 종과 질문에 대한 검색어를 JSON으로 추출한다. 종 자체 문서 확인을 항상 포함한다. 실제 추출 목록을 점검할 수 있어야 한다. | 필수 | 구현 |
| F2004 | 수집 · 외부 문서 수집 | 검색 후보를 프롬프트로 선별하고 본문·원문 출처를 저장한다. 동일 종임이 확인된 자체 문서는 선별·길이 제외보다 우선한다. 성공 캐시는 재수집하지 않는다. 문서 확인 실패는 사용자에게 안내하며 다른 종으로 대체하지 않는다. | 필수 | 구현 |
| F2005 | 색인 · 외부 문서 색인 | 본문을 설정된 길이·중복으로 청킹하여 species_docs에 색인한다. 종ID·문서ID·청크순번 조합으로 소유 범위를 구분하고 제목·출처·종 관계를 보존한다. 로컬 PDF는 페이지 경계를 유지한다. 설정 변경 후 캐시 본문으로 재색인할 수 있어야 한다. | 필수 | 구현 |
| F2006 | 검색 · 근거 검색 및 병합 | 선택 종 메타데이터를 반드시 포함하고 종 ID로 제한한 외부 문서를 의미 검색한다. 결과를 병합·중복 제거하며 Top-k를 설정으로 조정한다. 두 종 비교는 각 종의 소유 관계를 유지한다. | 필수 | 구현 |
| F2007 | 생성 · 근거 기반 답변 | LangGraph의 retrieve와 generate 두 노드로 구성한다. 메타데이터와 외부 문서 유형을 구분하여 전달하고 검색된 근거에만 의존한다. 문서에 없는 내용은 미확인으로 답한다. 과거·해외 기록을 현재 국내 사실로 단정하지 않아야 한다. | 필수 | 구현 |
| F2008 | 생성 · 근거 표시 | 주요 주장에 근거 번호를 붙이고 실제 인용된 유효한 근거만 제목·원문 출처와 함께 표시한다. 근거가 없으면 안내한다. 외부 문서의 라이선스·리비전과 로컬 PDF의 파일·페이지를 확인할 수 있어야 한다. | 필수 | 구현 |
| F2009 | UI · 종 선택과 질의응답 | 국명·학명 검색, 분류군·숫자 등급 필터로 종을 선택하고 채팅한다. 대화는 현재 세션에서 종별로 분리한다. 다른 종을 선택해도 기존 종의 기록이 섞이지 않아야 한다. | 필수 | 구현 |
