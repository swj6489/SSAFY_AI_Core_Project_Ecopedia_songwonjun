# 구현 검증 결과

검증일: 2026-10-21. Windows / Python 3.12.10. 명세의 핵심 라이브러리 버전 그대로 설치. `pip check` 의존성 충돌 없음. Python 문법 컴파일 검사 통과.

## 자동 테스트

`python -m unittest discover -s tests -v`: **21개 통과** (NF2002 영구 캐시 수정 후 재검증).

- 고유 종 282건·1급 68건·2급 214건·고정 ID·미확인 속성 표시.
- 로마자 및 로마숫자 등급 입력 정규화, 해조류를 조류로 오인하지 않는 필터.
- 잘못된 청킹 설정 거부.
- 청크 ID 및 정규화 본문 중복 제거, 비교 종 소유 관계 유지.
- 답변 본문의 실제 인용만 표시, 잘못된 번호 거부 및 인용 없음 안내.
- SQLite 캐시 영구 보관, 오래된 성공 기록 및 재시작 후 반복 질문 재수집 방지, 실패 후 재시도.
- 이용 조건 미확인 manifest 거부, 승인된 자체 작성 TXT의 출처 보존.
- 키·User-Agent 누락 안내 및 로그 자격증명 마스킹.
- 실제 ChromaDB에 282종 두 번 색인해도 282개 유지.
- 실제 ChromaDB 등급·분류군 필터와 종별 검색 격리.
- 문서 재분할·본문 변경 시 낡은 잔여 청크 제거.
- LangGraph retrieve/generate 실행, 메타데이터 강제 포함 및 색인 누락 처리.
- 실제 Chroma MMR 실행, 종 자체 문서가 관련 문서에 밀려 빠지지 않는 회귀 검사.
- Streamlit AppTest의 키 없는 목록 탐색, 종 검색·없는 검색 결과, 카드 이동 시 필터 초기화·종별 대화 분리.

단위·통합 테스트에서 LLM과 임베딩은 시험 대역이다. 아래 실 API 검증과 구분한다.

## GMS 실 API 검증

SSAFY 공식 모델별 안내를 확인한 뒤 GMS의 OpenAI 호환 주소로 연결했다. 키는 로컬 `.env`에만 저장했다.

| 확인 | 결과 |
|---|---|
| gpt-4o-mini JSON 응답 | 성공 |
| text-embedding-3-small | 1536차원 벡터 반환 |
| 실제 종 메타데이터 색인 | 282종 |
| 실제 자연어 '2급 포유류' | 6종 반환, 전부 숫자 등급 2 및 포유류 확인 |
| 삵·산양·사향노루 위키 문서 | 종 자체 문서 및 후보 수집·색인 성공 |
| 삵의 먹이·활동 시간 질문 | 외부 문서 인용을 포함한 답변 생성 |
| 산양·사향노루 비교 | 근거 번호를 포함한 표 및 설명 생성 |
| 특정 날짜의 정확한 야생 삵 개체수 | 문서에서 확인되지 않는다고 응답 |
| 실제 GMS 채팅 UI AppTest | 예외 0, 인용 근거 1개와 원문 버튼 1개 표시 |

실행 요약은 `실행검증_요약.json`을 확인한다. 전체 원문 청크와 실행 캐시는 로컬 `runtime`에만 보관한다.

검증 중 종 자체 문서가 관련 문서에 밀려 검색되지 않는 문제를 발견해 종 자체 근거 슬롯을 보장했다. 일부 LLM 응답의 JSON 필드·인용 누락을 확인해 strict JSON Schema와 근거 번호 검증·재생성으로 보완했다. SQLite 연결 종료 누락으로 발생한 Windows 파일 잠금 문제도 수정했다.

## 남은 검증과 제한

- 3종 중심의 소량 연결 검증이며 282종 전수 답변 정확성 검증이 아니다.
- 산양 비교 결과의 일부 분포·위협 항목은 충분한 근거를 활용하지 못하고 미확인으로 답했다. 실제 출처 충실성·재현율과 답변 품질을 추가 평가해야 한다.
- 종 메타데이터의 서식지·분포·위협 요인은 미수집 상태다. 해당 조건으로 탐색할 때는 미확인 정보를 충족으로 처리하지 않는다.
- 2022년 개정 종 목록을 사용한다. 2026년 현행 법령 전수 대조는 남아 있다.
- 공식 도감·국립생물자원관 본문은 권리 조건 미확정 상태로 자동 수집하지 않는다.
- F2015의 5개 질문 RAG 전후 비교 문서, 실제 복수 출처 결합 검증, 셀프·상호 체크리스트와 최종 화면 캡처는 남아 있다.
- Streamlit 서버 시작 메시지는 확인했으나 이 도구 환경의 별도 프로세스 간 localhost 연결은 확인하지 못했다. 화면 동작은 Streamlit AppTest로 검증했다. 실제 PC에서는 README 명령으로 서버를 실행한다.
